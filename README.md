## Descripción
SIGEAH-1.0 es una solución en Python diseñada para optimizar el registro, consulta, filtrado y actualización del estado de emergencias humanitarias. Implementa buenas prácticas de desarrollo de software, gestión por tarjetas Kanban, automatización CI/CD y análisis continuo de seguridad.

---

## Requisitos del Sistema
- Python 3.10+
- Git
- Dependencias indicadas en `requirements.txt`
